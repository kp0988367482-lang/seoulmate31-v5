# SEOULMATE 31 — v5

居韓第 10 年，台灣人在韓國的第一手資訊基地。純靜態 HTML，零依賴、零建置，任何靜態主機（GitHub Pages / Vercel / Netlify）直接部署。

## 頁面

| 檔案 | 用途 |
|------|------|
| `index.html` | 銷售落地頁：服務與定價（落地全包 / 留學全包 / 就業全包 / 1:1 諮詢）、匯款流程 |
| `success.html` | 付款確認頁：確認匯款後導入 LINE 群 |
| `video-automation.html` | **影片自動化工作台（內部工具）**：短影音腳本、文案、排程一條線生成 |

## 影片自動化工作台

把行銷策略 v1.0 的短影音系統工具化，開檔案就能用，不需要伺服器：

- **腳本產生器** — 選影片類型（現場實錄 / 真相揭露 / 客戶故事 / 熱點借力 / 限量日常）＋ 主題 ＋ 長度（15 / 30 / 45 秒），自動生成分鏡表（時間軸、口播、螢幕字卡、畫面建議），一鍵複製口播稿。
- **文案產生** — 每支腳本同步生成 IG / TikTok 發佈文案與 hashtag，複製即發。
- **本週排程** — 照策略頻率（現場實錄每週 3、真相揭露 2、客戶故事 1、週日熱點）自動排一週片單，主題輪換不重複，可匯出 CSV 或複製文字版。
- **鉤子庫** — 全部「三句話公式」第一句的成品鉤子，按類型篩選、單句複製。

腳本邏輯全部遵守品牌語言守則：只用「你」和「我們」、短句、不說「諮詢」說「先聊一次」、正文不出現韓文。

### 上線注意事項

- `index.html` 匯款帳號（`[請填入帳號]` / `[請填入戶名]`）與 LINE 連結（`XXXXXXXXXX`）仍是佔位符，上線前必須替換。
- `video-automation.html` 是內部工具，部署時建議不要從公開頁面連結它。
